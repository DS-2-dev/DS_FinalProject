# DS_FinalProject

## Notes on dataset and reproducibility

- Analyses in this repository use the full cleaned dataset derived from the Google Forms export: **n = 102** participants. One missing `time_spent_hours` value was imputed with the sample median during cleaning; this is documented in `notebooks/01_cleaning.ipynb`.

To reproduce the data and figures, run the repository cleaning and plotting scripts from the project root using the project virtual environment Python (see notebooks for exact commands).
